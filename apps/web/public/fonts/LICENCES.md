# Polices

Les deux polices du site sont libres, sous la licence SIL Open Font License 1.1
(<https://openfontlicense.org>). Elles sont hébergées avec le site : le
navigateur des visiteurs n'appelle aucun service tiers pour les charger.

| Fichier                  | Police     | Auteurs                                              | Source       |
| ------------------------ | ---------- | ---------------------------------------------------- | ------------ |
| `dm-sans-latin.woff2`    | DM Sans    | Colophon Foundry, Jonny Pinhorn, Indian Type Foundry | Google Fonts |
| `bebas-neue-latin.woff2` | Bebas Neue | Dharma Type (Ryoichi Tsunekawa)                      | Google Fonts |

Sous-ensemble « latin » (français et anglais). DM Sans est une police à
graisse variable : un seul fichier couvre les graisses 400 à 700.

La v1 écrit le nom et la note des cartes en Kiona. Sa licence n'est pas encore
vérifiée pour un site et un dépôt publics : Bebas Neue la remplace.
